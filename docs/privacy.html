싱크 메모 개인정보처리방침

시행일: 2026년 11월 5일 · 운영: live1379 (live1379@gmail.com)

1. 수집하는 정보

싱크 메모는 운영자가 관리하는 서버가 없으며, 이용자의 메모·개인정보를 운영자에게 전송하거나 수집하지 않습니다.

2. 메모가 저장되는 곳

메모는 이용자의 기기 안(앱·브라우저 저장소)에 먼저 저장됩니다. 이용자가 "구글 연결"을 선택한 경우에만, 이용자 본인의 Google 드라이브 안 앱 전용 숨김 폴더(appDataFolder)에 메모가 저장되어 기기 간에 동기화됩니다. 이 폴더는 이용자 본인과 이 앱만 접근할 수 있습니다.

3. Google 계정 권한

앱은 https://www.googleapis.com/auth/drive.appdata 권한 하나만 요청합니다. 이 권한으로는 이 앱이 만든 동기화 데이터만 읽고 쓸 수 있으며, 이용자 드라이브의 다른 파일·이메일·연락처 등에는 접근할 수 없습니다. Google 사용자 데이터는 동기화 기능에만 사용되며, 제3자에게 제공·판매하거나 광고에 사용하지 않습니다. 이 앱의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 잠긴 메모

이용자가 잠근 메모는 기기에서 암호화(AES-GCM)된 뒤 저장·동기화되며, 암호는 어디에도 저장되지 않습니다.

5. 삭제

앱 설정의 "연결 해제"로 동기화를 멈출 수 있고, 앱을 삭제하면 기기 안의 데이터가 지워집니다. 드라이브에 저장된 동기화 데이터는 Google 드라이브 설정 → 앱 관리에서 "싱크 메모"의 숨겨진 앱 데이터를 삭제하여 지울 수 있습니다. 또한 Google 계정의 보안 설정(https://myaccount.google.com/permissions)에서 언제든 앱의 접근 권한을 취소할 수 있습니다.
