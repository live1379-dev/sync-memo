# 싱크 메모 설치 지시서 (Claude 용)

이 폴더는 **싱크 메모** 설치 꾸러미다. 맥·안드로이드 공용 오프라인 우선 메모 앱으로, 메모는 사용자 **본인 구글 드라이브의
appDataFolder(앱 전용 숨김 폴더)** 에 동기화된다. 서버 없음.
사용자가 "설치해줘"·"셋팅해줘"라고 하면 아래 순서대로 끝까지 진행한다.
사용자는 개발자가 아닐 수 있다 — 사람이 직접 눌러야 하는 것은 **한 번에 하나씩, 어디를 누르는지까지** 알려 준다.
구글 클라우드 화면 순서·문구는 `설명서/1-구글드라이브-연결-단계별.md` ①~⑧, 메모 옮기기는 `설명서/2-아이클라우드-메모-옮기기.md` 를 그대로 따른다.

## 핵심 원칙 — 사용자 혼자, 사용자 계정으로

- 사용자가 **자기 구글 클라우드 프로젝트**를 만들어 앱을 등록한다. 꾸러미를 준 사람에게 허락·값을 받으러 보내지 않는다.
- 폰 앱은 원본 APK 를 그대로 깔지 않는다. 구글은 (패키지 + SHA-1) 을 한 프로젝트에만 등록하게 해서 원본 지문은 이미 다른 사람 것이다.
  → `도구/폰앱-내키로-서명.sh` 로 **사용자 전용 키로 다시 서명**한 `폰/SyncMemo-내폰용.apk` 를 쓰고, 그 SHA-1 을 사용자 프로젝트에 등록한다.
- 폰(Android 클라이언트)과 맥(데스크톱 클라이언트)은 **같은 프로젝트**에 만들어야 한다(appDataFolder 가 프로젝트마다 따로라서).
- 폰·맥·구글 클라우드는 **같은 Gmail**.

## 구성

| 경로 | 내용 |
|---|---|
| `폰/SyncMemo-원본.apk` | 서명 재료. 직접 설치하지 않는다 |
| `도구/폰앱-내키로-서명.sh` | 사용자 키(`~/Library/Application Support/SyncMemo-서명키`, 없으면 생성)로 재서명 → `폰/SyncMemo-내폰용.apk` + `내-폰앱-지문.txt`(SHA-1). Java 필요(없으면 brew 로 설치, brew 도 없으면 끝 코드 2 + Temurin 안내). 끝 코드 0·2·1 |
| `도구/apksigner.jar` | 서명 도구 (Android SDK, Apache 2.0) |
| `맥/싱크 메모 (맥용).zip` | 맥 앱 (macOS 12 이상, 애플 실리콘·인텔, 자체 서명) |
| `도구/맥설치.sh` | zip → `/Applications/싱크 메모.app`, 격리 표시 제거, 실행 확인. 끝 코드 0·1 |
| `도구/폰설치.sh` | USB 폰에 내폰용 APK adb 설치. 끝 코드 0·2·1 (다른 서명 앱이 깔려 있으면 2) |
| `도구/맥메모-내보내기.js` | 맥 메모 앱(아이클라우드 포함) → 가져오기용 JSON (JXA, 읽기만) |
| `맥-구글연결값.txt` | 사용자가 ⑧ 에서 만든 데스크톱 클라이언트 ID·보안 비밀번호를 적어 두는 칸 |

## 진행 순서

1. **맥 앱**: `zsh 도구/맥설치.sh` → 끝 코드 0.
2. **내 폰용 앱**: `zsh 도구/폰앱-내키로-서명.sh` → 끝 코드 0 이 나올 때까지(2 면 안내 전하고 다시). 출력된 SHA-1 을 사용자에게 보여 준다.
   - Homebrew 가 없어서 설치해야 하면 **먼저 묻는다**(관리자 암호 필요). 싫다면 Temurin .pkg 경로로 안내.
3. **구글 클라우드 등록**: 설명서 A ①~⑧ 을 한 단계씩. 각 단계 끝에 "어떤 화면이 보이세요?" 로 확인하고 넘어간다.
   - ⑦ 패키지 이름 `net.live1379.syncmemo`, SHA-1 은 `내-폰앱-지문.txt` 값. "이미 사용 중" 오류 = 원본 지문을 넣은 것.
   - ⑧ 창의 두 값은 사용자가 `맥-구글연결값.txt` 에 적게 한다. 사용자가 채팅에 붙여 넣어도 다시 출력·저장하지 않는다.
   - 콘솔 화면 문구는 바뀔 수 있다 — 버튼이 안 보인다고 하면 콘솔 위 검색창에 기능 이름을 치게 한다.
4. **폰 설치·연결**: `폰/SyncMemo-내폰용.apk` 를 폰으로(카톡 나에게·드라이브) 보내 설치, 또는 USB 로 `zsh 도구/폰설치.sh`.
   그다음 설명서 B.
5. **맥 연결**: 설명서 C. 확인은 D(폰에서 `연결 시험` 메모 → 맥 ↻).
6. **아이클라우드 메모 옮기기**(사용자가 원하면) — 설명서 2.
   - 내가 돌려도 된다: `osascript -l JavaScript 도구/맥메모-내보내기.js ~/Desktop/맥메모.json`
     ("메모 제어 허용" 창 → 사용자가 허용. 거부했으면 시스템 설정 > 개인정보 보호 및 보안 > 자동화 > 터미널(또는 Claude) > 메모)
   - 출력 `메모 N개 · 폴더 M개 내보냄 (건너뜀 K)` 를 그대로 전한다. K = 잠긴 메모.
   - 가져오기는 사용자가 앱에서: 설정(⌘,) → 백업 → "백업·맥 메모 가져오기 (.json)" → 가져오기 → `맥메모.json`.
   - 끝나면 `~/Desktop/맥메모.json` 을 지우자고 권한다(메모 전체가 평문). 지우기 전에 묻는다. JSON 내용은 읽지 않는다.

## 확인 (기계로 본 것만 "됐다"고 말한다)

- 맥 실행: `pgrep -f "싱크 메모.app/Contents/MacOS/SyncMemo"` · 버전: `defaults read "/Applications/싱크 메모.app/Contents/Info" CFBundleShortVersionString`
- 재서명 확인: `java -jar 도구/apksigner.jar verify --print-certs 폰/SyncMemo-내폰용.apk` 의 SHA-1 = `내-폰앱-지문.txt`
- 폰 설치: `adb shell dumpsys package net.live1379.syncmemo | grep versionName`
- 연결·동기화는 사용자 화면으로: 설정 '상태: 연결됨 ✓', D 의 `연결 시험` 메모

## 하지 말 것

- 꾸러미를 준 사람에게 허락·값을 받으라고 안내하지 않는다(필요 없다).
- `~/Library/Application Support/SyncMemo-서명키` 를 지우지 않는다(지우면 업데이트가 안 되고 ⑦ 을 다시 해야 한다).
- 사용자 메모 데이터(`~/Library/WebKit/net.live1379.syncmemo`, `~/Library/Application Support/SyncMemo`)를 지우거나 읽지 않는다.
- 맥 메모 앱 원본을 고치거나 지우지 않는다.
