# 싱크 메모 설치 지시서 (Claude 용)

이 폴더는 **싱크 메모** 설치 꾸러미다. 맥·안드로이드 공용 오프라인 우선 메모 앱으로, 메모는 사용자 **본인 구글 드라이브의
appDataFolder(앱 전용 숨김 폴더)** 에 동기화된다. 서버 없음.
사용자가 "설치해줘"·"셋팅해줘"라고 하면 아래 순서대로 끝까지 진행한다.
사용자는 개발자가 아닐 수 있다 — 사람이 직접 눌러야 하는 것은 **한 번에 하나씩, 어디를 누르는지까지** 알려 준다.
화면 문구·순서는 `설명서/1-구글드라이브-연결-단계별.md`, `설명서/2-아이클라우드-메모-옮기기.md` 에 정확히 적혀 있다 — 그걸 그대로 안내한다.

## 구성

| 경로 | 내용 |
|---|---|
| `폰/SyncMemo.apk` | 안드로이드 앱 (안드로이드 10 이상). 패키지 `net.live1379.syncmemo` |
| `맥/싱크 메모 (맥용).zip` | 맥 앱 (macOS 12 이상, 애플 실리콘·인텔 겸용, 자체 서명) |
| `도구/맥설치.sh` | zip → `/Applications/싱크 메모.app`, 격리 표시 제거, 실행 확인. 끝 코드 0 성공 · 1 실패 |
| `도구/폰설치.sh` | USB 로 붙은 폰에 adb 설치. 끝 코드 0 · 2 사람 할 일 · 1 실패 |
| `도구/맥메모-내보내기.js` | 맥 메모 앱(아이클라우드 포함) → 가져오기용 JSON (JXA) |
| `맥-구글연결값.txt` | 맥 앱 구글 연결용 데스크톱 클라이언트 ID·보안 비밀번호 (꾸러미 준 사람이 채움) |
| `설명서/` | 사용자용 설명서 |

## 꼭 알아야 할 구조 (헷갈리지 말 것)

- 앱 등록(구글 클라우드 프로젝트)은 **꾸러미 만든 사람 것을 같이 쓴다.** 사용자에게 구글 클라우드 콘솔에서 프로젝트·API·클라이언트를
  **만들게 하지 않는다.** 이유: 폰 APK 는 서명(SHA-1)으로 만든 사람 프로젝트에 묶여 있고, appDataFolder 는 프로젝트마다 따로라서
  맥만 다른 프로젝트로 연결하면 폰과 맥이 서로 다른 숨김 폴더를 보게 된다.
- 그래도 메모는 **사용자 본인 드라이브**에 저장된다(로그인한 계정의 드라이브).
- 만든 사람 프로젝트가 '테스트' 상태면 사용자 Gmail 이 테스트 사용자로 등록돼 있어야 로그인된다 →
  "액세스 차단됨"이 나오면 **사용자 Gmail 주소를 꾸러미 준 사람에게 보내라**고 안내한다. 내가 해결할 수 없다.

## 설치 순서

1. **맥 앱**: `zsh 도구/맥설치.sh`. 끝 코드 0 이 나오면 다음.
2. **폰 앱**: 사용자에게 고르게 한다.
   - 파일로(쉬움): `폰/SyncMemo.apk` 를 폰으로 보내(카카오톡 나에게 보내기·구글 드라이브 등) 눌러 설치, "출처를 알 수 없는 앱" 허용
   - USB: 폰 설정 > 휴대전화 정보 > 소프트웨어 정보 > **빌드번호 7번 탭** → 개발자 옵션 > **USB 디버깅** → 케이블 → 폰에 뜬 허용 → `zsh 도구/폰설치.sh`
3. **구글 연결** — `설명서/1-구글드라이브-연결-단계별.md` A(폰)·B(맥)·C(확인) 를 한 단계씩 안내한다.
   - 먼저 `맥-구글연결값.txt` 두 값이 채워졌는지 본다. 비어 있으면 **멈추고** 사용자에게 꾸러미 준 사람에게 받아 오라고 한다.
     값을 대신 만들거나 추측하지 않는다.
   - 맥 앱 설정 칸에 붙여넣기는 사용자가 한다(⌘, → '데스크톱 앱 OAuth 클라이언트 ID' · '클라이언트 보안 비밀번호').
     값을 화면에 다시 출력하지 않는다.
   - 폰과 맥은 **같은 구글 계정**이어야 한다.
4. **아이클라우드 메모 옮기기**(사용자가 원하면, 보통 원한다) — `설명서/2-아이클라우드-메모-옮기기.md`.
   - 내가 직접 돌려도 된다: `osascript -l JavaScript 도구/맥메모-내보내기.js ~/Desktop/맥메모.json`
     (처음엔 "메모 제어 허용" 창 → 사용자가 허용. 거부했으면 시스템 설정 > 개인정보 보호 및 보안 > 자동화 > 터미널(또는 Claude) > 메모)
   - 출력 `메모 N개 · 폴더 M개 내보냄 (건너뜀 K)` 를 사용자에게 그대로 전한다. K = 잠긴 메모(잠금 해제 후 다시 하면 들어감).
   - 가져오기는 사용자가 앱에서 한다: 설정(⌘,) → 백업 → "백업·맥 메모 가져오기 (.json)" → 가져오기 → `맥메모.json`.
   - 끝나면 `~/Desktop/맥메모.json` 을 지우자고 권한다(메모 전체가 평문으로 들어 있다). 지우기 전에 사용자에게 묻는다.
   - JSON 내용을 읽지 않는다(남의 메모다). 개수 확인이 필요하면 스크립트 출력 줄만 본다.

## 확인 (기계로 본 것만 "됐다"고 말한다)

- 맥 실행 중: `pgrep -f "싱크 메모.app/Contents/MacOS/SyncMemo"`
- 맥 버전: `defaults read "/Applications/싱크 메모.app/Contents/Info" CFBundleShortVersionString`
- 폰 설치: `adb shell dumpsys package net.live1379.syncmemo | grep versionName`
- 연결·동기화는 사용자 화면으로 확인한다: 설정 '상태: 연결됨 ✓', 폰에서 쓴 `연결 시험` 메모가 맥에 보이는지(↻).

## 하지 말 것

- 사용자의 메모 데이터(`~/Library/WebKit/net.live1379.syncmemo`, `~/Library/Application Support/SyncMemo`)를 지우거나 읽지 않는다.
- `맥-구글연결값.txt` 값을 다른 곳에 보내거나 저장소·채팅에 붙이지 않는다.
- 맥 메모 앱의 원본 메모를 고치거나 지우지 않는다(내보내기 스크립트는 읽기만 한다).
