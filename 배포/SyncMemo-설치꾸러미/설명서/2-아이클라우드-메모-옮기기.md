# 2. 맥의 아이클라우드 메모(애플 메모) 옮겨오기 — 단계별

맥 **'메모' 앱**에 있는 메모(아이클라우드 + 내 Mac)를 폴더째 싱크 메모로 가져옵니다.
**원래 메모는 지워지지도 바뀌지도 않습니다** — 복사만 합니다.

## 무엇이 옮겨지나

| 옮겨짐 | 안 옮겨짐 |
|---|---|
| 메모 글·서식(제목, 굵게, 목록, 체크리스트 모양 등) | **잠긴 메모** — 내용을 읽을 수 없어 건너뜀 |
| 폴더 (같은 이름으로 만들어짐) | '최근 삭제된 항목' 폴더 |
| 처음 만든 날짜·마지막 수정한 날짜 | 첨부 파일(PDF·문서 등)은 빠질 수 있음 — 중요한 첨부는 따로 확인 |
| 아이클라우드·'나의 Mac' 등 메모 앱의 모든 계정 | |

## 하기 전에

- [ ] 맥 **메모 앱**을 한 번 열어 **아이클라우드 동기화가 끝났는지** 확인합니다(메모 개수가 아이폰과 비슷한지).
      맥에 아직 내려오지 않은 메모는 옮길 수 없습니다.
- [ ] 옮기고 싶은 **잠긴 메모는 미리 잠금 해제**합니다(메모 열기 → 자물쇠 → 잠금 제거).
- [ ] 싱크 메모를 먼저 설치하고 **구글 연결까지** 해 두면, 가져온 메모가 바로 폰에도 갑니다
      (`1-구글드라이브-연결-단계별.md`).

## 단계

### ① 메모 앱에서 파일로 내보내기

1. **터미널**을 엽니다 (Spotlight ⌘Space → "터미널").
2. 아래를 입력합니다. 꾸러미 폴더를 다운로드에 풀었다면 그대로 복사해서 붙여넣으면 됩니다.
   ```
   cd ~/Downloads/SyncMemo-설치꾸러미
   osascript -l JavaScript 도구/맥메모-내보내기.js ~/Desktop/맥메모.json
   ```
3. **"터미널이(가) '메모'를 제어하려고 합니다"** 창이 뜨면 → **허용**
   - 실수로 '허용 안 함'을 눌렀다면: 시스템 설정 > 개인정보 보호 및 보안 > **자동화** > 터미널 > **메모** 켜기 → 2번 다시
4. 기다립니다. 메모가 1,000개면 1~3분쯤. 끝나면 이런 줄이 나옵니다.
   ```
   메모 1893개 · 폴더 24개 내보냄 (건너뜀 3) → /Users/이름/Desktop/맥메모.json
   ```
   - **건너뜀** 숫자 = 잠긴 메모 개수입니다.
5. 바탕화면에 **`맥메모.json`** 파일이 생겼는지 확인합니다.

### ② 싱크 메모로 가져오기

1. 싱크 메모 맥 앱 → **⌘,** (설정)
2. 아래로 내려 **백업** 칸 → **"백업·맥 메모 가져오기 (.json)"** 줄의 **가져오기** 버튼
3. 바탕화면의 **`맥메모.json`** 선택
4. 목록에 메모와 폴더가 생깁니다. 수정한 날짜 순서가 메모 앱과 같으면 성공입니다.
5. 구글이 연결돼 있으면 잠시 뒤 **폰에도** 같은 메모가 나타납니다(메모가 많으면 첫 동기화에 몇 분).

### ③ 정리

- 바탕화면의 `맥메모.json` 은 메모 전체가 들어 있는 파일입니다. 가져오기가 끝났으면 **지워 주세요**(남한테 보내지 마세요).

## 자주 묻는 것

- **두 번 가져오면 메모가 두 배가 되나요?** 아니요. 같은 메모는 하나로 유지되고, 날짜가 틀어진 메모만 바로잡습니다.
- **가져온 뒤에 메모 앱에서 고친 건요?** 자동으로 따라오지 않습니다. 다시 ①~② 를 하면 됩니다.
  이후로는 싱크 메모에서 쓰시는 걸 권합니다.
- **아이폰 메모는요?** 아이폰 메모는 아이클라우드를 거쳐 맥 메모 앱에 이미 들어와 있으니, 맥에서 한 번 하면 같이 옮겨집니다.
- **"Error: 응용 프로그램이 실행 중이 아닙니다" / 아무것도 안 나옴** — 메모 앱을 한 번 켜 두고 다시 실행하세요.
