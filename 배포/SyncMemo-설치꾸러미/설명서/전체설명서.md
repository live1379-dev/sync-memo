# 싱크 메모 — 전체 설명서 (1.4.7)

맥과 안드로이드 폰에서 같이 쓰는 메모 앱입니다. 애플 메모 + 삼성 노트를 합친 느낌으로 만들었습니다.

## 1. 어떻게 저장·동기화되나

- 메모는 **각 기기에 먼저 저장**됩니다. 비행기 안, 지하, 인터넷 없는 곳에서도 그대로 쓰고 고칠 수 있습니다.
- 인터넷이 되면 **내 구글 드라이브의 '앱 전용 숨김 폴더'** 와 맞춰집니다. 드라이브 화면에는 보이지 않고, 드라이브 용량을 조금 씁니다.
- 서버가 따로 없습니다. 메모는 **내 드라이브에만** 있어서 앱을 만든 사람도 볼 수 없습니다.
- 두 기기에서 같은 메모를 동시에 고치면 최신 것을 원본으로 두고, 다른 쪽은 **"(충돌 사본)"** 메모로 남깁니다. 어떤 경우에도 고친 내용이 사라지지 않습니다.
- **잠긴 메모**는 기기에서 암호를 건 뒤 올라갑니다. 드라이브엔 제목만 그대로 보입니다. 잠금 암호를 잊으면 아무도 못 엽니다.
- 바로 맞추고 싶으면 목록 위 **↻** 버튼, 폰은 목록 맨 위에서 **아래로 당겼다 놓기**.

## 2. 처음 연결 — 자세한 단계는 `1-구글드라이브-연결-단계별.md`

| 기기 | 하는 일 |
|---|---|
| 폰 | 앱을 열고 **"구글 연결 필요 — 눌러서 연결"** 을 누르거나 설정(폴더 칸 맨 위 톱니바퀴) → **구글 연결** → 계정 고르기 |
| 맥 | 설정(**⌘,**) → `맥-구글연결값.txt` 의 **클라이언트 ID** · **클라이언트 보안 비밀번호** 붙여넣기 → **구글 연결** → 브라우저에서 계정 고르기 → 허용 |

- 폰과 맥 모두 **같은 구글 계정**으로 연결해야 같은 메모가 보입니다.
- **"확인되지 않은 앱"** 화면이 나오면 **고급 → 싱크 메모(으)로 이동**. 개인이 만든 앱이라 구글 심사를 받지 않아 뜨는 안내입니다.
- 한 번 연결하면 계속 유지됩니다. 앱이 볼 수 있는 건 **이 앱이 만든 숨김 파일**(와 첨부할 때 이 앱이 올린 파일)뿐입니다.
- 연결하기 전에 쓴 메모는 "이 기기에만 저장 중" 상태로 있다가, 연결하면 같이 올라갑니다.

## 3. 기능

**정리** — 폴더(색상) · 태그(`#태그`) · 고정 · 스마트 보기(할 일 남은 메모, 잠긴 메모) · 최근 삭제됨(30일 보관) ·
목록/그리드 · 정렬(수정·생성·제목) · 날짜별 묶음 · 검색(찾은 글자 표시) · 메모 색상

**글쓰기** — 제목/머리말/부머리말/본문/고정폭 · 굵게·기울임·밑줄·취소선 · 형광펜 5색 · 글자색 5색 ·
목록·번호(`1. ` 쓰고 엔터 → 다음 줄 `2.` 자동) · 들여쓰기(Tab / Shift+Tab) · 인용 ·
체크리스트(체크하면 맨 아래로, 모두 해제, 체크한 항목 삭제) · 표(행·열 추가/삭제, Tab 으로 칸 이동) ·
주소를 쓰면 자동 링크 · 되돌리기/다시 실행 버튼

**넣기** — 사진(자동 압축, 붙여넣기·끌어넣기) · **손글씨/그리기**(펜 필압, 형광펜, 지우개, S펜 손바닥 무시) ·
**음성 녹음** · 다른 메모 연결 · 템플릿(할 일·장보기·회의·설교·일기)

**폰 전용** — 메모 **길게 누르기** → 고정·폴더 이동·복제·색상·삭제 · **오른쪽으로 밀기 = 고정, 왼쪽으로 밀기 = 삭제** ·
다른 앱에서 **공유 → 싱크 메모** · 홈 화면 바로가기(새 메모·할 일) · 알림창(빠른 설정) '새 메모' 버튼(설정에서 추가) ·
**파일 첨부**(📎 또는 녹음·전사 파일을 공유받기 → 내 드라이브 `싱크 메모 첨부` 폴더에 올리고 메모엔 링크) ·
펼친 폴드 세로 화면에선 목록·메모 반반 · 덱스(외부 모니터) 지원

**맥 전용** — 목록에서 메모 **더블클릭 → 그 메모만 새 창** · 창 위쪽 빈 곳 잡고 끌기 · 메뉴 단축키

**내보내기** — 공유 · 마크다운 저장 · 인쇄/PDF · 백업 내보내기/가져오기(설정 → 백업) · 글자 수 · 다크 모드(시스템 따라감)

> 메모 길게 누르기 메뉴의 **"회의록 만들기 / 콘티 준비하기 (Claude)"** 는 만든 사람의 작업 환경용입니다.
> 누르면 내 드라이브 `싱크 메모 Claude 요청` 폴더에 요청 파일만 남고 아무 일도 일어나지 않습니다. 쓰지 않으셔도 됩니다.

## 4. 맥 메모(애플 메모)에서 옮겨오기 — 자세한 단계는 `2-아이클라우드-메모-옮기기.md`

1. 터미널에서(꾸러미 폴더 안):
   ```
   osascript -l JavaScript 도구/맥메모-내보내기.js ~/Desktop/맥메모.json
   ```
2. 처음엔 **"메모 제어 허용"** 창 → 허용. 메모가 많으면 몇 분 걸립니다.
3. 싱크 메모 설정 → 백업 → **"백업·맥 메모 가져오기 (.json)" 가져오기** → 바탕화면의 `맥메모.json`.
   폴더는 같은 이름으로 만들어지고, 원래 수정한 날짜가 유지됩니다.
- **잠긴 맥 메모는 읽을 수 없어 건너뜁니다** — 먼저 잠금을 풀고 하세요.
- 같은 파일을 다시 가져와도 됩니다(날짜가 틀어진 메모만 바로잡습니다).

## 5. 문제 해결

| 증상 | 해결 |
|---|---|
| 맥: "확인되지 않은 개발자" 로 안 열림 | `zsh 도구/맥설치.sh` 로 다시 설치. 또는 Finder > 응용 프로그램 > 싱크 메모 **오른쪽 클릭 → 열기** |
| 맥: "설정에서 데스크톱 클라이언트 ID를 먼저 넣어주세요" | `맥-구글연결값.txt` 두 값을 설정(⌘,)에 붙여넣기. 비어 있으면 꾸러미 준 사람에게 받기 |
| 구글 화면 "액세스 차단됨 / 이 앱은 테스트 중" | 꾸러미 준 사람에게 **내 구글 이메일**을 알려 주세요(테스트 사용자 등록 필요) |
| 구글 화면 "확인되지 않은 앱" | 고급 → 싱크 메모(으)로 이동 |
| "구글 연결이 끊겼어요 — 다시 연결" | 눌러서 다시 계정 고르기. 메모는 그대로입니다 |
| 폰과 맥 메모가 다름 | 두 기기의 **구글 계정이 같은지** 설정에서 확인 → ↻ 지금 동기화 |
| "오프라인" 이 계속 뜸 | 목록 맨 위에서 아래로 당겨 놓기(폰) / ↻ |
| 폰: 설치가 안 됨 | 안드로이드 10 이상인지 확인, "출처를 알 수 없는 앱" 허용. 예전에 다른 곳에서 받은 싱크 메모가 있으면 지우고 다시 설치 |
| 음성 녹음이 안 됨 | 맥: 시스템 설정 > 개인정보 보호 및 보안 > 마이크 > 싱크 메모 켜기 / 폰: 앱 정보 > 권한 > 마이크 |

## 6. 지우려면

- 맥: 응용 프로그램에서 싱크 메모를 휴지통으로. 기기 메모까지 지우려면 `~/Library/WebKit/net.live1379.syncmemo` 와
  `~/Library/Application Support/SyncMemo` 도 지웁니다.
- 폰: 앱 지우기.
- 드라이브의 숨김 데이터: 드라이브 웹 > 설정(톱니) > **앱 관리** > 싱크 메모 > **숨겨진 앱 데이터 삭제**.
