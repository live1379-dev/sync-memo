# 1. 내 구글 드라이브 연결하기 — 단계별

싱크 메모는 **내 구글 드라이브**에 메모를 보관합니다. 그러려면 구글에 "내 싱크 메모 앱"을 **내 계정으로 한 번 등록**해야 합니다.
처음 한 번만 하는 일이고, 순서대로 따라 하면 20~30분이면 끝납니다. 누구에게 허락받을 필요 없이 혼자 다 할 수 있습니다. 무료입니다.

## 먼저 알아 두기

- 앞으로 만드는 것은 전부 **내 계정 안**에 생깁니다. 메모도 **내 드라이브**에만 저장되고, 꾸러미를 준 사람은 볼 수 없습니다.
- 메모는 드라이브의 **'앱 전용 숨김 폴더'** 에 들어가서 드라이브 화면엔 안 보입니다. 앱은 내 다른 파일을 볼 수 없습니다.
- 폰·맥·구글 클라우드 모두 **같은 구글 계정**(Gmail) 하나로 합니다. 계정이 섞이면 연결이 안 됩니다.
- 화면 문구는 구글이 가끔 바꿉니다. 이름이 조금 달라도 비슷한 버튼을 누르면 됩니다. 화면 위 **검색창**에 이름을 쳐도 찾아집니다.

## 준비

- [ ] 맥 앱을 설치했다 (`zsh 도구/맥설치.sh`)
- [ ] **내 폰용 앱을 만들었다** — 터미널에서 꾸러미 폴더로 가서
      ```
      zsh 도구/폰앱-내키로-서명.sh
      ```
      끝나면 **SHA-1** 값이 나오고 `내-폰앱-지문.txt` 에도 저장됩니다(예: `92:A4:50:…:F7`). 아래 ⑦ 에서 씁니다.
      - "Java 가 필요합니다" 가 나오면: https://adoptium.net → **Temurin 21 LTS · macOS · .pkg** 받기 → 두 번 눌러 설치 → 다시 실행
      - 이때 만들어지는 내 서명 키(`~/Library/Application Support/SyncMemo-서명키`)는 **지우지 마세요.**
        새 버전 꾸러미를 받으면 이 스크립트만 다시 돌리면 같은 지문으로 업데이트됩니다.

## A. 구글 클라우드에 내 앱 등록 (맥 브라우저에서)

### ① 구글 클라우드 들어가기
1. 브라우저에서 **https://console.cloud.google.com** 접속
2. 오른쪽 위 계정이 **내 Gmail** 인지 확인 (아니면 눌러서 바꾸기)
3. 처음이면 "서비스 약관" 창 → 국가 **대한민국** · 약관 동의 체크 → **동의 및 계속**
   - 무료 체험·결제 정보 입력 안내가 떠도 **하지 않아도 됩니다**(닫기). 이 작업은 결제가 필요 없습니다.

### ② 프로젝트 만들기
1. 왼쪽 위 **프로젝트 선택** 상자(로고 옆) 클릭 → 오른쪽 위 **새 프로젝트**
2. 프로젝트 이름: `싱크 메모` → **만들기**
3. 오른쪽 위 종 모양 알림에 완료가 뜨면 **프로젝트 선택** → `싱크 메모` 클릭
   - 화면 위쪽에 `싱크 메모` 가 보여야 합니다. 이후 모든 단계는 이 프로젝트 안에서 합니다.

### ③ 구글 드라이브 API 켜기
1. 맨 위 검색창에 `Google Drive API` 입력 → 결과의 **Google Drive API** 클릭
2. 파란 **사용** 버튼 클릭 → '관리' 화면으로 바뀌면 끝

### ④ 앱 이름 정하기 (OAuth 동의 화면)
1. 검색창에 `Google 인증 플랫폼` (또는 `OAuth 동의 화면`) → 클릭 → **시작하기**
2. **앱 정보**: 앱 이름 `싱크 메모` · 사용자 지원 이메일 = **내 Gmail** → **다음**
3. **대상**: **외부** 선택 → **다음**
4. **연락처 정보**: 내 Gmail → **다음**
5. **완료**: 정책 동의 체크 → **계속** → **만들기**

### ⑤ 권한 범위 넣기
1. 왼쪽 메뉴 **데이터 액세스** → **범위 추가 또는 삭제**
2. 오른쪽 창 아래 **수동으로 범위 추가** 칸에 아래 두 줄을 붙여넣고 → **표에 추가**
   ```
   https://www.googleapis.com/auth/drive.appdata
   https://www.googleapis.com/auth/drive.file
   ```
   (위에 있는 표에서 `drive.appdata` 를 찾아 체크해도 됩니다)
3. **업데이트** → 화면 아래 **저장**

### ⑥ 앱 게시 (7일마다 로그인 풀리는 것 막기)
1. 왼쪽 메뉴 **대상** → 게시 상태 '테스트' 옆 **앱 게시** → **확인**
   - '인증 필요' 같은 안내가 나와도 그냥 확인하면 됩니다. 나 혼자 쓰는 앱이라 구글 심사는 필요 없습니다.
   - 대신 로그인할 때 "확인되지 않은 앱" 경고가 한 번 뜹니다(아래 C 에서 넘어가는 법).

### ⑦ 폰용 클라이언트 만들기
1. 왼쪽 메뉴 **클라이언트** → **+ 클라이언트 만들기**
2. 애플리케이션 유형: **Android**
3. 이름: `싱크 메모 폰`
4. 패키지 이름: `net.live1379.syncmemo`  (그대로 복사)
5. SHA-1 인증서 디지털 지문: `내-폰앱-지문.txt` 의 값 붙여넣기
6. **만들기** — 폰은 이걸로 끝입니다(따로 적어 둘 값 없음).
   - "이미 사용 중" 오류가 나면 원본 APK 지문을 넣은 것입니다. 준비 단계의 서명 스크립트를 돌렸는지, 그 지문을 넣었는지 확인하세요.

### ⑧ 맥용 클라이언트 만들기
1. 다시 **+ 클라이언트 만들기**
2. 애플리케이션 유형: **데스크톱 앱** · 이름: `싱크 메모 맥` → **만들기**
3. **"OAuth 클라이언트 생성됨"** 창에 값 두 개가 나옵니다. ★**이 창을 닫기 전에** 복사하세요.
   - **클라이언트 ID** (`…apps.googleusercontent.com`) → `맥-구글연결값.txt` 첫 줄에
   - **클라이언트 보안 비밀번호** (`GOCSPX-…`) → 둘째 줄에
   - **JSON 다운로드** 도 눌러 두면 안전합니다.
   - 이미 닫았다면: **클라이언트** → `싱크 메모 맥` → 오른쪽 **보안 비밀번호 추가** → 새 값 복사

구글 클라우드 작업은 여기까지입니다. 🎉

## B. 폰 연결

1. 폰에 **`폰/SyncMemo-내폰용.apk`** 를 설치합니다(카카오톡 나에게 보내기·구글 드라이브로 옮겨 누르기, 또는 USB 로 `zsh 도구/폰설치.sh`).
   - ⚠ `SyncMemo-원본.apk` 가 아니라 **내폰용** 입니다.
   - 예전에 다른 곳에서 받은 싱크 메모가 깔려 있으면 **먼저 지우고** 설치하세요("앱이 설치되지 않았습니다"가 뜨는 원인).
2. 앱을 열고 **"구글 연결 필요 — 눌러서 연결"** 을 누릅니다.
   - 안 보이면: 왼쪽 폴더 칸 맨 위 **'싱크 메모'** 옆 **톱니바퀴(설정)** → **구글 연결**
3. 계정 선택 → **A 에서 쓴 같은 Gmail**
4. "확인되지 않은 앱" → **고급**(또는 세부정보 표시) → **싱크 메모(으)로 이동(안전하지 않음)** → **계속**
   - 내가 방금 만든 앱이라 안전합니다. 구글 심사를 안 받아서 뜨는 안내입니다.
5. 설정의 **상태: 연결됨 ✓** 이 보이면 끝

## C. 맥 연결

1. 싱크 메모 앱 → **⌘,** (설정)
2. **데스크톱 앱 OAuth 클라이언트 ID** 칸 ← `맥-구글연결값.txt` 의 클라이언트 ID
3. **클라이언트 보안 비밀번호** 칸 ← 보안 비밀번호
   - ⚠ 앞뒤에 **띄어쓰기가 붙지 않게**.
4. **구글 연결** → 브라우저가 열림 → **같은 Gmail** → "확인되지 않은 앱" → 고급 → 이동 → **계속**
5. 브라우저에 **"✓ 싱크 메모 연결 완료 — 이 창을 닫고 앱으로 돌아가세요"** → 탭 닫기
6. 설정의 **상태: 연결됨 ✓** 확인 → **지금 동기화**

## D. 잘 됐는지 확인

1. 폰에서 새 메모 `연결 시험` 작성
2. 맥 싱크 메모 목록 위 **↻**
3. 맥에 `연결 시험` 이 보이면 성공. 지우셔도 됩니다.

## 이런 화면이 나오면

| 화면·문구 | 이유 | 할 일 |
|---|---|---|
| 폰: **"액세스 차단됨"** / 연결 실패 코드 10·12500 | ⑦ 의 패키지 이름·SHA-1 이 다르거나, 원본 APK 를 깔았음 | `내-폰앱-지문.txt` 값과 ⑦ 값이 같은지, 폰에 **내폰용** APK 를 깔았는지 확인. 고친 뒤 5분쯤 기다렸다 다시 |
| **"액세스 차단됨: … 테스트 중"** | ⑥ 게시를 안 했음 | ⑥ 하기 (또는 **대상 → 테스트 사용자**에 내 Gmail 추가) |
| **"확인되지 않은 앱"** | 심사 안 받은 개인 앱(정상) | 고급 → 싱크 메모(으)로 이동 |
| 맥: **"설정에서 데스크톱 클라이언트 ID를 먼저 넣어주세요"** | C-2·3 값이 비었음 | 붙여넣기 |
| 맥: **invalid_client** / **unauthorized_client** | 값이 잘못 붙여짐, 또는 ⑧ 을 '데스크톱 앱'이 아닌 유형으로 만듦 | 두 칸 지우고 다시 붙여넣기 / ⑧ 다시 |
| 폰·맥 메모가 서로 안 보임 | 두 기기 계정이 다르거나, 폰·맥 클라이언트가 **다른 프로젝트**에 있음 | 같은 Gmail · ⑦⑧ 이 같은 `싱크 메모` 프로젝트 안인지 확인 |
| **"구글 연결이 끊겼어요 — 다시 연결"** | 오래 안 썼거나 비밀번호 변경 | 눌러서 다시 연결. 메모는 그대로 |

연결을 끊어도(연결 해제) 기기에 있는 메모는 지워지지 않습니다.
