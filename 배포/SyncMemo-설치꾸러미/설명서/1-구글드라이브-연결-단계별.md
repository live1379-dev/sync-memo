# 1. 내 구글 드라이브 연결하기 — 단계별

싱크 메모는 **내 구글 드라이브**에 메모를 보관합니다. 이 연결만 끝내면 폰과 맥이 같은 메모를 봅니다.
천천히 순서대로 하시면 10분이면 끝납니다.

## 먼저 알아 두기 (안심하셔도 되는 것)

- 메모는 **내 드라이브**에 저장됩니다. 꾸러미를 준 사람의 드라이브가 아닙니다. 준 사람도 내 메모를 볼 수 없습니다.
- 드라이브 안의 **'앱 전용 숨김 폴더'** 에 저장되어 드라이브 화면에는 안 보입니다. 내 다른 파일은 앱이 볼 수 없습니다.
- 구글 클라우드 콘솔에 들어가거나 API 를 직접 만들 필요는 **없습니다.** 앱 등록은 준 사람이 이미 해 두었고,
  나는 **내 계정으로 "허용"만** 누르면 됩니다.
  (맥에서만 준 사람이 보내 준 값 두 개를 붙여넣는 단계가 하나 더 있습니다.)
- **폰과 맥은 꼭 같은 구글 계정**으로 연결하세요. 계정이 다르면 메모가 따로 놉니다.

## 준비물 체크

- [ ] 사용할 **구글 계정**(Gmail 주소)을 정했다 — 폰에 로그인된 계정과 같은 것이 편합니다
- [ ] 그 Gmail 주소를 꾸러미 준 사람에게 **알려 줬다** (준 사람이 "허용 명단"에 넣어야 로그인이 됩니다)
- [ ] `맥-구글연결값.txt` 에 **클라이언트 ID**·**클라이언트 보안 비밀번호** 두 값이 채워져 있다
      (비어 있으면 준 사람에게 받으세요)

---

## A. 폰 연결 (값 입력 없음)

1. 폰에서 **싱크 메모** 앱을 엽니다.
2. 화면의 **"구글 연결 필요 — 눌러서 연결"** 을 누릅니다.
   - 안 보이면: 왼쪽 폴더 칸을 열고 맨 위 **'싱크 메모'** 옆 **톱니바퀴(설정)** → **구글 연결**
3. **계정 선택** 창 → 사용할 구글 계정을 누릅니다.
4. **"싱크 메모에서 구글 계정에 액세스하려고 합니다"** 창
   - 목록에 **"Google Drive 에서 이 앱의 자체 구성 데이터를 보고, 관리하고, 삭제"** 가 보입니다 → **계속(허용)**
   - **"확인되지 않은 앱"** 화면이 먼저 나오면 → 아래 **고급**(또는 **세부정보 표시**) → **싱크 메모(으)로 이동(안전하지 않음)**
     → 개인이 만든 앱이라 구글 심사를 안 받아서 나오는 안내입니다. 앱이 볼 수 있는 건 위의 숨김 폴더뿐입니다.
5. 설정 화면 **상태: 연결됨 ✓** 이 보이면 끝. 이후로는 다시 묻지 않습니다.

> 나중에 📎 파일 첨부를 처음 쓸 때 **"이 앱으로 만든 Google Drive 파일만 보기·수정"** 허용을 한 번 더 묻습니다 → 허용.
> 첨부 파일은 내 드라이브 `싱크 메모 첨부` 폴더에 들어갑니다(이건 보이는 폴더).

## B. 맥 연결 (값 두 개 붙여넣기)

1. **싱크 메모** 앱을 엽니다(Spotlight ⌘Space → "싱크 메모").
2. **⌘,** (커맨드 + 쉼표) 를 눌러 **설정**을 엽니다.
3. **구글 드라이브 동기화** 칸에 입력란이 두 개 있습니다.
   - `맥-구글연결값.txt` 를 텍스트 편집기로 엽니다.
   - **클라이언트 ID** 줄의 값(`…apps.googleusercontent.com` 으로 끝남)을 복사 → 설정의 **데스크톱 앱 OAuth 클라이언트 ID** 칸에 붙여넣기
   - **클라이언트 보안 비밀번호** 줄의 값(`GOCSPX-` 로 시작)을 복사 → **클라이언트 보안 비밀번호** 칸에 붙여넣기
   - ⚠ 앞뒤에 **띄어쓰기가 붙지 않게** 하세요. 붙으면 연결이 실패합니다.
4. **구글 연결** 버튼을 누릅니다 → 기본 브라우저(사파리·크롬)가 열립니다.
5. 브라우저에서 **폰과 같은 계정**을 고릅니다.
6. **"확인되지 않은 앱"** → **고급** → **싱크 메모(으)로 이동(안전하지 않음)**
7. 권한 화면 → **계속**
8. 브라우저에 **"✓ 싱크 메모 연결 완료 — 이 창을 닫고 앱으로 돌아가세요"** 가 보이면 탭을 닫습니다.
9. 싱크 메모 설정의 **상태: 연결됨 ✓** 확인 → **지금 동기화** 를 한 번 누릅니다.

## C. 잘 됐는지 확인

1. 폰에서 새 메모를 하나 씁니다. 제목: `연결 시험`
2. 맥 싱크 메모에서 목록 위 **↻** 를 누릅니다 (몇 초 걸릴 수 있음).
3. 맥에 `연결 시험` 메모가 보이면 성공입니다. 그 메모는 지우셔도 됩니다.

## 이런 화면이 나오면

| 화면·문구 | 이유 | 할 일 |
|---|---|---|
| **"액세스 차단됨: 싱크 메모는 Google 인증 절차를 완료하지 않았습니다"** / "개발자가 승인한 테스터만" | 내 Gmail 이 아직 허용 명단에 없음 | 준 사람에게 **내 Gmail 주소**를 보내고, 추가됐다고 하면 다시 연결 |
| **"확인되지 않은 앱"** | 개인 앱이라 심사 안 받음(정상) | 고급 → 싱크 메모(으)로 이동 |
| 맥: **"설정에서 데스크톱 클라이언트 ID를 먼저 넣어주세요"** | B-3 값이 비었음 | 두 값을 붙여넣기 |
| 맥: **invalid_client** / **unauthorized_client** | 값이 잘못 붙여짐(띄어쓰기·일부만 복사) | 두 칸을 지우고 다시 붙여넣기 |
| 폰·맥 메모가 서로 안 보임 | 두 기기의 계정이 다름 | 설정에서 연결된 계정 확인 → **연결 해제** 후 같은 계정으로 다시 연결 |
| **"구글 연결이 끊겼어요 — 다시 연결"** | 오래 안 썼거나 비밀번호 변경 | 눌러서 다시 계정 고르기. 메모는 그대로 |

연결을 끊어도(연결 해제) 기기에 있는 메모는 지워지지 않습니다.
