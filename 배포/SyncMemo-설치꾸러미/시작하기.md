# 싱크 메모 — 시작하기

맥과 안드로이드 폰에서 **같은 메모를 같이 쓰는 앱**입니다.
메모는 각 기기에 먼저 저장되고(인터넷이 없어도 됨), 인터넷이 되면 **내 구글 드라이브의 숨김 폴더**로 맞춰집니다.
서버가 없고, 앱 등록도 **내 구글 계정에 직접** 하기 때문에 메모는 **오직 내 드라이브에만** 있습니다.
꾸러미를 준 사람을 포함해 누구에게도 허락받거나 연결할 필요가 없습니다.
맥 **메모 앱(아이클라우드)** 에 있던 메모도 폴더째 옮겨올 수 있습니다.

## 순서 한눈에

1. 맥 앱 설치 · 내 폰용 앱 만들기
2. **내 구글 드라이브 연결** (구글 클라우드에 내 앱 등록 — 처음 한 번, 20~30분) → `설명서/1-구글드라이브-연결-단계별.md`
3. 폰 앱 설치 · 폰·맥 연결
4. **아이클라우드 메모 옮기기** → `설명서/2-아이클라우드-메모-옮기기.md`

## 가장 쉬운 방법 — Claude 에게 맡기기

1. 이 압축 파일을 풉니다(예: `다운로드/SyncMemo-설치꾸러미`).
2. 터미널을 열고 아래 두 줄을 입력합니다.
   ```
   cd ~/Downloads/SyncMemo-설치꾸러미
   claude
   ```
   (Claude 데스크톱 앱이라면 이 폴더를 작업 폴더로 열면 됩니다.)
3. **"싱크 메모 설치하고 내 드라이브 연결, 아이클라우드 메모 옮기기까지 해줘"** 라고 말합니다.

Claude 가 폴더 안의 `CLAUDE.md` 를 읽고 설치 → 구글 클라우드 등록 안내 → 연결 → 메모 옮기기까지 함께 진행합니다.
구글 화면에서 사람이 눌러야 하는 것은 한 단계씩, 어디를 누르는지까지 알려 줍니다.

## 직접 하려면

```
zsh 도구/맥설치.sh              # 맥 앱 (macOS 12 이상, 애플 실리콘·인텔)
zsh 도구/폰앱-내키로-서명.sh     # 내 폰용 앱 + 구글에 넣을 SHA-1 지문
```
그다음 `설명서/1-…` 을 처음부터 따라 하시고, `설명서/2-…` 로 메모를 옮기면 됩니다.
폰에는 **`폰/SyncMemo-내폰용.apk`** 를 설치합니다(`SyncMemo-원본.apk` 는 서명 재료라 직접 깔지 않습니다).

모든 기능·단축키·문제 해결은 `설명서/전체설명서.md` 에 있습니다.
