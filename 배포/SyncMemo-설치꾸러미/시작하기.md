# 싱크 메모 — 시작하기

맥과 안드로이드 폰에서 **같은 메모를 같이 쓰는 앱**입니다.
메모는 각 기기에 먼저 저장되고(인터넷이 없어도 됨), 인터넷이 되면 **내 구글 드라이브의 숨김 폴더**로 맞춰집니다.
서버가 없어서 내 메모는 **내 드라이브에만** 있습니다. 다른 사람(꾸러미를 준 사람 포함)은 볼 수 없습니다.
맥 **메모 앱(아이클라우드)** 에 있던 메모도 폴더째 옮겨올 수 있습니다.

## 순서 한눈에

1. 앱 설치 — 맥, 폰
2. **내 구글 드라이브 연결** → `설명서/1-구글드라이브-연결-단계별.md`
3. **아이클라우드 메모 옮기기** → `설명서/2-아이클라우드-메모-옮기기.md`

시작 전에: **내 Gmail 주소를 꾸러미 준 사람에게** 알려 주세요(로그인 허용 명단에 넣어야 합니다).
그리고 `맥-구글연결값.txt` 에 값 두 개가 채워져 있는지 보세요. 비어 있으면 준 사람에게 받으세요.

## 가장 쉬운 방법 — Claude 에게 맡기기

1. 이 압축 파일을 풉니다(예: `다운로드/SyncMemo-설치꾸러미`).
2. 터미널을 열고 아래 두 줄을 입력합니다.
   ```
   cd ~/Downloads/SyncMemo-설치꾸러미
   claude
   ```
   (Claude 데스크톱 앱이라면 이 폴더를 작업 폴더로 열면 됩니다.)
3. **"싱크 메모 설치하고 아이클라우드 메모도 옮겨줘"** 라고 말합니다.

Claude 가 폴더 안의 `CLAUDE.md` 를 읽고 설치 → 구글 연결 안내 → 메모 옮기기까지 진행합니다.
사람이 직접 눌러야 하는 것(구글 계정 고르기, 허용 버튼 등)은 하나씩 알려 줍니다.

## 직접 설치하려면

**맥(macOS 12 이상, 애플 실리콘·인텔 모두)**
```
zsh 도구/맥설치.sh
```

**폰(안드로이드 10 이상)** — 둘 중 편한 것
- `폰/SyncMemo.apk` 를 폰으로 보내서(카카오톡 나에게 보내기·구글 드라이브 등) 눌러 설치합니다.
  "출처를 알 수 없는 앱" 창이 뜨면 **설정 → 이 출처 허용** 을 켭니다.
- 또는 USB 로 연결해서 `zsh 도구/폰설치.sh`

그다음 `설명서/1-…`, `설명서/2-…` 를 순서대로 따라 하시면 됩니다.
모든 기능·단축키·문제 해결은 `설명서/전체설명서.md` 에 있습니다.
