# 싱크 메모 꾸러미 — 전달 전 오너가 할 일

받는 사람은 구글 클라우드에 손대지 않는다. 앱 등록(오너 프로젝트)을 같이 쓰고, 메모는 각자 본인 드라이브 appDataFolder 에 저장된다.
(받는 사람이 프로젝트를 따로 만들면 안 되는 이유: 폰 APK 는 SHA-1 로 오너 프로젝트에 묶여 있고, appDataFolder 는 프로젝트마다 따로라
맥만 다른 프로젝트면 폰·맥이 서로 다른 숨김 폴더를 본다.)

## 1. 받는 사람 Gmail 허용 (프로젝트가 '테스트' 상태일 때만)

console.cloud.google.com → 싱크 메모 프로젝트 → **Google 인증 플랫폼 → 대상(Audience)**
- 게시 상태가 **프로덕션** 이면 할 일 없음(누구나 "확인되지 않은 앱 → 고급 → 이동" 으로 로그인).
- **테스트** 면 → **테스트 사용자 → + 사용자 추가** → 받는 사람 Gmail 입력 → 저장. (테스트 상태는 7일마다 로그인이 풀린다 — 프로덕션 권장)

## 2. `맥-구글연결값.txt` 채우기

맥 앱 설정의 비밀번호 칸은 가려진 입력이라 거기서 복사가 안 된다. 구글 클라우드에서 꺼낸다.
console.cloud.google.com → **Google 인증 플랫폼 → 클라이언트** → 유형 **데스크톱** 인 클라이언트 클릭
- **클라이언트 ID** → 복사해서 txt 의 `클라이언트 ID:` 뒤에
- **클라이언트 보안 비밀번호** — 화면에 보이면 복사. 가려져서 안 보이면 **보안 비밀번호 추가** → 새 값 복사.
  ⚠ 기존 비밀번호는 **사용 중지하지 말 것**(오너 맥이 그걸로 연결돼 있다).

채운 txt 는 꾸러미 zip 에 넣지 말고 **카톡 등으로 따로** 보내는 걸 권장(zip 이 돌아다녀도 값이 안 퍼지게).
넣어서 보내도 큰일은 아니다 — 값만으로는 남의 메모·계정에 접근할 수 없다(로그인은 각자 계정으로).

## 3. 꾸러미 다시 만들기 (앱을 고친 뒤)

```
zsh tools/make-package.sh      # 저장소 루트에서. APK·맥(유니버설) 빌드 → 배포/SyncMemo-설치꾸러미.zip
```
